本文说明如何在 Linux 内网用 Docker 搭建一个简单软件库：同事打开链接就能按目录下载，不用登录；管理员登录后台后上传软件、创建目录。数据目录固定为 `/opt/filebrowser`​。本方案按 `docker run` 部署，不用 Compose，也不用自定义 Docker 网络。

## 前言

内网需要一个集中下载点，把常用软件和开发工具放到固定地址上。同事打开链接就能按目录下载，不必登录；管理员单独使用后台上传安装包、创建分类目录。

本方案在 Linux 上用 Docker 部署：Nginx 提供免登录下载，File Browser 提供管理后台，两者共用 `/opt/filebrowser/software`​。使用 `docker run`，不使用 Compose，也不创建自定义 Docker 网络。

## 环境准备

准备一台已安装 Docker 的 Linux 服务器，确认 **80**、**8080** 端口空闲，镜像选择最新的稳定版本：

```shell
docker pull filebrowser/filebrowser:v2.63.23
docker pull nginx:1.30.4-alpine
```

## 软件库安装

### 创建数据目录

官方 File Browser 镜像默认以 UID `1000`​ 运行。目录若是 `root` 创建且未改属主，启动时会报错。

```bash
sudo mkdir -p /opt/filebrowser/{software,database,config,nginx}
sudo chown -R 1000:1000 /opt/filebrowser
sudo chmod -R u+rwX /opt/filebrowser
sudo chmod 755 /opt/filebrowser/software
```

### 启动File Browser

```bash
docker run -d \
  --name filebrowser \
  --restart unless-stopped \
  -e TZ=Asia/Shanghai \
  -p 8080:80 \
  -v /opt/filebrowser/software:/srv \
  -v /opt/filebrowser/database:/database \
  -v /opt/filebrowser/config:/config \
  filebrowser/filebrowser:v2.63.23
```

注意，命令里不需要添加`FB_NOAUTH`​，否则谁都能上传、删除。现在也不要加 `FB_BASE_URL`​，管理后台直接访问 8080。第一次访问通过`docker logs filebrowser`​查看管理员密码，具体格式为`User 'admin' initialized with randomly generated password: SbBCus3qNG3gYkXZ`，登录后需立即修改密码。

### 修改File Browser 新建文件权限

这里需要专门强调，File Browser 按安全默认写出了“只有自己能进”的目录，也就是说，通过其他方式调用只会出现无权限，为了解决这个问题，采用方式如下：

```bash
docker stop filebrowser

docker run --rm \
  -v /opt/filebrowser/database:/database \
  filebrowser/filebrowser:v2.63.23 \
  config set -d /database/filebrowser.db --fileMode 0644 --dirMode 0755

find /opt/filebrowser/software -type d -exec chmod 755 {} \;
find /opt/filebrowser/software -type f -exec chmod 644 {} \;

docker start filebrowser
```

### 配置并启动Nginx

Nginx 只做免登录列目录和下载，不反代 File Browser，因此不需要 Docker 网络。

```bash
sudo tee /opt/filebrowser/nginx/default.conf >/dev/null <<'EOF'
server {
    listen 80;
    server_name _;
    charset utf-8;

    root /usr/share/nginx/html;
    autoindex on;
    autoindex_exact_size off;
    autoindex_localtime on;

    location / {
        try_files $uri $uri/ =404;
    }
}
EOF
```

添加完配置文件后，使用docker来启动nginx容器。

```bash

docker run -d \
  --name nginx \
  --restart unless-stopped \
  -e TZ=Asia/Shanghai \
  -p 80:80 \
  -v /opt/filebrowser/software:/usr/share/nginx/html:ro \
  -v /opt/filebrowser/nginx/default.conf:/etc/nginx/conf.d/default.conf:ro \
  nginx:1.30.4-alpine
```

### 设置Nginx可读权限

File Browser 上传的文件属主是 `1000`​，Nginx 容器里的用户不同。目录必须是 `755`​，文件必须是 `644`，否则后台看得到、80 端口 403 或列表为空。初始化时，以及同事反馈下载页看不到新文件时，执行：

```bash
sudo chown -R 1000:1000 /opt/filebrowser/software
sudo find /opt/filebrowser/software -type d -exec chmod 755 {} \;
sudo find /opt/filebrowser/software -type f -exec chmod 644 {} \;
```

### 放行防火墙

firewalld：

```
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

ufw：

```
sudo ufw allow 80/tcp
sudo ufw allow 8080/tcp
```

80 给全员下载。8080 只给管理员，有条件时可以只对管理网段开放。

### 快速生成

可以在外网创建一个 software 目录，通过ai将所需要的所有软件放到这个目录下并划分好，然后直接迁移到内网对应目录下即可，只需要修改权限：

```bash
chown -R 1000:1000 /opt/filebrowser/software
find /opt/filebrowser/software -type d -exec chmod 755 {} \;
find /opt/filebrowser/software -type f -exec chmod 644 {} \;
```
